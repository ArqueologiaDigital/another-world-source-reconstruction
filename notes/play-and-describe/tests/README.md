# The check's own check

`annotation_queue.py --check` is the whole idempotency guarantee of this
directory. It is the only thing in the repository that can see a proposal row
citing a sentence that no longer exists, or a row written and never applied: a
rename moves no bytes, so `make test` is blind to both, and the sentence behind
a citation is the one kind of evidence here that cannot be regenerated by
re-running anything. A guarantee asserted by the program that provides it is
worth nothing, so every way the bookkeeping is known to break is built here as a
throwaway repository and fed to the probe. What passes is the exit code **and**
the id in the message -- a check that fails without naming the offending line
sends the next agent reading all of `notes/` by hand.

    sh notes/play-and-describe/tests/run.sh         # 11 cases
    sh notes/play-and-describe/tests/mutants.sh     # 5 faults: does run.sh notice?

Either takes a path to a candidate probe as `$1`.

| fixture | the question it asks | passes when |
| --- | --- | --- |
| `clean` | the storm entry and the CORROBORATES row it earned -- the control, and every case below is this tree with one thing broken | exit 0 |
| `orphan` | a verdict row for an id no log line yields, the shape a hand edit of `verdicts.tsv` leaves | exit 1, naming the id |
| `edited` | one word of a cited line changed: the price of a content-derived id, and why the log is append-only | exit 1 naming the orphaned citation, and the re-typed line listed `OPEN` |
| `proposed` | a table cites a live id and the tree does not define the name it proposes -- a rejected row, or the cartridge no-op that prints "N proposed, 0 rejected" and reverts everything | exit 1, `PROPOSED`, naming the id |
| `both` | one id carrying a verdict *and* a citation, which claim it twice and disagree | exit 1, naming the id |
| `held` | a `HELD` row with an empty `settled_by`, indistinguishable from an abandonment | exit 1, naming the id |
| `forbidden` | a `bulk_rename` typing `CAVES_COLUMN_AT_136_165`, which is the click's own x,y | exit 0 -- it is admissible evidence -- but flagged against `docs/NAMING.md` where the queue is read |
| `stable` | appending a second sentence does not move the first's id | the id before and after the append are the same, exit 0 |
| `documented` | the `ann:cff7052605ce` this directory's README and `CLAUDE.md` both quote, recomputed from the log in the tree | it still hashes to that. Not a fixture: it is the assertion that nothing has been rewritten under the citations already pointing into it. Skipped before the first play session |

Each fixture is four files -- log, `verdicts.tsv`, one proposal table, one
`.asm` -- built from scratch on every run under `fixtures/` and `git init`-ed,
because step 0 refuses to derive consumption from a log with uncommitted lines
and a case has to measure the check rather than the harness. They are deleted at
exit, `KEEP=1` leaves them to be read, and `fixtures/` is not committed because
`run.sh` is the record of them.

`run.sh` passing proves nothing on its own -- a suite whose fixtures are wrong
passes against anything. So `mutants.sh` breaks the probe five ways, one rebound
attribute each, and requires the cases that fault touches to fail: `--check`
exiting 0 while still printing the problems (5 cases), `--check` failing without
naming the id (5), hop two skipped so a cited name is believed rather than read
out of `src/levels/<branch>/<STAGE>.asm` (1, `proposed`), the `NAMING.md` flag
removed (1, `forbidden/flag`), and the rejected sha256-over-canonicalised-JSON
id scheme in place of sha1 over the raw line (3, including the control). The
injection is by attribute rather than by patching source text, so it survives
the probe being edited and says so loudly when a name it rebinds has moved.

The names in the fixtures are fictional and none of them is a claim about the
game: `CINEMATIC_CAVES_TRAP_COLUMN_F00` exists here only to be a name the tree
does or does not define. Nothing in this directory asserts that any name is
right, because nothing mechanical can.
