# INTRO (msdos): the same qualifier, and the same six frames

Evidence and renders in `proposals_chahi_amiga_1991__INTRO_pulse_far.md`.
msdos carries the identical six `_AMIGA_EXTRA` constants -- they were the
same collision in both branches -- and the same fifteen `..._PULSE_F*`
named one commit ago. Nothing changes hands; the fifteen take the `_NEAR_`
qualifier and the six stop claiming to be lightning.
