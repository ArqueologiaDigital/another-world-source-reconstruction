# INTRO (msdos): the same four marks

Argument and measurements in `proposals_chahi_amiga_1991__INTRO_particles.md`.

These are **not** matched by `canonical_md5`: all four share one hash with six
other one-path marks in the stage, because the bridge cannot see colour
(`notes/cross-port-art/colour_blind_hashes.py`). They are matched by the offset
and the draw site, both of which msdos holds identically -- the same four
offsets, the same two loops, the same eight y values in the same order.
